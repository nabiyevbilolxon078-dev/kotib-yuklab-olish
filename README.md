# Kotib

**Kotib — ovozli kotibingiz.** Gapirganingizni istalgan dasturda o'zbekcha matnga aylantiradi.

### Yuklab olish
- **Windows 10 / 11:** `Kotib.exe` — ikki marta bosing. Ko'k oyna chiqsa: «More info» → «Run anyway».
- **macOS 11+ (Apple M1 va yangilari):** `Kotib-mac.dmg` — oching, Kotib'ni «Applications» ga torting. Birinchi marta: o'ng tugma → «Open». So'ng Accessibility va Input Monitoring ruxsatini bering.
