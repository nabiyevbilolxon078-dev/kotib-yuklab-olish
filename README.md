# Kotib

**Kotib — ovozli kotibingiz.** Gapirganingizni istalgan dasturda o'zbekcha matnga aylantiradi.

### Yuklab olish
- **Windows 10 / 11:** [Kotib.exe](https://github.com/nabiyevbilolxon078-dev/kotib-yuklab-olish/raw/main/Kotib.exe) — ikki marta bosing. Ko'k oyna chiqsa: «More info» → «Run anyway».
- **macOS 11+ (Apple M1 va yangilari):** [Kotib-mac.dmg](https://github.com/nabiyevbilolxon078-dev/kotib-yuklab-olish/raw/main/Kotib-mac.dmg) — oching, Kotib'ni «Applications» ga torting. Ogohlantirish chiqsa: System Settings → Privacy & Security → «Open Anyway». So'ng Accessibility va Input Monitoring ruxsatini bering.
